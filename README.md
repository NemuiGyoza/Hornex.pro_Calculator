# Hornex Crafting Calculator

A visual crafting simulator and budget analysis tool built for **Hornex.pro** to calculate statistical odds, expected costs, and success rates for high-tier petals.

## Live Demo
[Hornex.pro Calculator](https://nemuigyoza.github.io/Hornex.pro_Calculator/)

## Features
* **Supported Recipes:** Ultra → Super (1.00%) and Super → Hyper (0.51%).
* **Custom Budgeting:** Simulate sessions with budgets up to 5,000 petals.
* **Statistical Analysis:** Computes craft chance, average loss on fail, expected cost per success, expected rolls, overall success probability, and most likely outcomes.
* **Interactive Probability Chart:** Visualizes success percentage breakdowns using responsive scale bars.

## How it Works
Based on internal game rules, each roll costs 5 petals. Failures recover a randomized portion of petals (equal 25% chance to lose 1, 2, 3, or 4 petals), while successes consume the full 5 petals.

## Technologies Used
* HTML5, CSS3/Modern UI, JavaScript (ES6)
